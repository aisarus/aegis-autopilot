# Aegis 1.1.0 — Cosmic Graph

- Настоящий WebGL-граф проектов и чатов: вращение, zoom, глубина, светящиеся связи и плавный фокус камеры.
- ChatGPT скрыт в режиме карты и открывается только при выборе реального чат-узла.
- WebContentsView появляется поверх правой части workspace; закрытие возвращает пользователя в 3D-космос.
- Состояние узлов отражает автопилот: зелёный — активен, розовый — ошибка/пауза, золотой — обычная ветка.
- Денежный предохранитель Gemini: дневной лимит в долларах, по умолчанию $0.50.
- Перед API-вызовом резервируется $0.02; потенциально превышающий лимит запрос не отправляется.
- Сохраняется отдельный лимит числа Gemini-вызовов (по умолчанию 250 в сутки).
- При достижении денежного лимита конкретный чат ставится на паузу, а не продолжает расходовать API.
