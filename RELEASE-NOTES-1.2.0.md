# Aegis 1.2.0 — Minimal Autopilot

- Полностью удалён 3D/космический интерфейс.
- Постоянный двухпанельный режим: управление слева, оригинальный ChatGPT справа.
- Одна кнопка запускает до трёх закреплённых проектов.
- Общие кнопки остановки и немедленной проверки.
- Денежный лимит и лимит Gemini-вызовов видны на главном экране.
- Журнал и диагностика доступны одним нажатием.
- После серии ошибок автопилот больше не выключается навсегда: используется бесконечный backoff с восстановлением.
- Чаты в состоянии watching периодически перепроверяются без Gemini-вызова, пока не появится новый ответ.
- Gemini вызывается только для нового завершённого ответа ChatGPT.
