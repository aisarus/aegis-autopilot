# Aegis 0.8.1 — Autopilot resilience

- Автопилот больше не выключается из-за одного пропущенного DOM-сигнала ChatGPT.
- Добавлен независимый watchdog состояния каждые 8 секунд.
- Ответ определяется по ID последнего turn и хэшу текста, а не только по кнопке Stop.
- Добавлена проверка стабильности текста ответа перед запуском следующего шага.
- Неоднозначное завершение генерации запускает повторную сверку вместо паузы.
- Протухшее ожидание ответа автоматически освобождается через 12 минут и перепроверяется.
- Усилен fallback-детектор streaming/aria-busy.

Ограничение: приложение зависит от DOM веб-интерфейса ChatGPT. Watchdog и несколько независимых признаков сильно снижают вероятность пропусков, но изменение разметки ChatGPT всё ещё может потребовать обновления адаптера.
